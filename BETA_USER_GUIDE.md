# Beta User Guide

Welcome to the Autopilon private beta. This is a short, practical guide —
for what the product actually is, see `PRODUCT_OVERVIEW.md`.

## Getting access

Signup is intentionally closed during the beta — there's no public
registration page. You're reading this because you were invited directly.
See "How you get access" below for exactly how that works right now.

## Your first few minutes

1. **Log in** at `https://autopilon.com` (or open the Android app, once
   installed) with the account the admin set up for you.
2. You'll see a short **welcome walkthrough** the first time you log in —
   it explains what an agent, skill, integration, and automation are, and
   lets you pick what you want help with. You can skip it anytime and
   revisit these concepts later — nothing is locked behind it.
3. From the walkthrough (or the Dashboard's quick actions), **install a
   starter agent** that matches what you want to do, or build one from
   scratch under **Agents → New Agent**.
4. If your agent needs an integration (e.g. Gmail, WhatsApp, WooCommerce),
   connect it under **Integrations** — you'll see clearly which ones are
   connected, not connected, or need something from you first.
5. Go to **AI Chat**, pick your agent, and start talking to it.

## What to expect

- Responses take a few seconds — that's a real AI provider round-trip,
  not a bug.
- If an agent needs to do something significant (like sending a real
  message or changing an order), it may ask for your confirmation first
  rather than acting silently.
- Your usage is tracked per organization — see **Organizations** for your
  current plan and limits. During the beta, limits are set generously;
  tell us if you hit one unexpectedly.

## Reporting problems or ideas

Click **Give Feedback** in the sidebar (or Settings on mobile) at any
time. Pick "Report a bug," "Request a feature," or "General feedback,"
write what happened, and send — no email required, it goes straight to
the team.

## How you get access

There's no public signup and no automated email invite system yet — access
is granted directly by an admin creating your account. If you're sharing
this guide with someone else you want in the beta, have them contact
whoever gave you access, rather than trying to sign up on the site
themselves (that flow is deliberately closed right now).

## Known limitations right now

- No email notifications — everything happens inside the app (see
  `PRODUCT_OVERVIEW.md` for the full list of what's not built yet).
- Android only for mobile — no iOS build exists yet.
- If AI Chat shows an error mentioning "provider," that's almost always
  temporary — try again in a minute, and report it via Give Feedback if
  it keeps happening.

Thanks for testing this early — real feedback from a small group is
exactly how this gets better before a wider release.
